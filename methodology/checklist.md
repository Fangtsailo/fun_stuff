# 一頁式檢核表：這是好公司嗎？

> 快速版。細節請看各編號檔案。每項打 ✅ / ⚠️ / ❌。

---

## A. 生意（→ 01）

- [ ] 能說出至少 1 個護城河來源（網路效應 / 成本優勢 / 無形資產 / 轉換成本 / 有效規模）
- [ ] 護城河趨勢是變寬或穩定，不是變窄
- [ ] 五力平均 ≥ 3.5
- [ ] 市占 3 年趨勢是增加或持平
- [ ] 漲價後銷量沒掉（有定價能力）
- [ ] 單一客戶 < 10% 營收

## B. 財務（→ 02）

- [ ] **ROIC > WACC，且利差在擴大**
- [ ] ROE 主要來自利潤率，不是槓桿（權益乘數 < 3x）
- [ ] Net Debt / EBITDA < 2.5x
- [ ] 流動比率 > 1.5x
- [ ] 利息保障倍數 > 3x
- [ ] CCC 下降或為負
- [ ] ΔNWC / Δ營收 < 15%

## C. 盈餘品質（→ 03）

- [ ] **Piotroski F-Score ≥ 7**
- [ ] CFO / 淨利持續 > 1.0x（< 0.7x = 紅旗）
- [ ] FCF / 淨利 > 80%
- [ ] SBC < 營收 5%
- [ ] 應收帳款成長沒有快於營收
- [ ] 商譽 < 總資產 30%
- [ ] 無更換會計師、無重編、無持續經營疑慮
- [ ] 會計品質分數 ≥ 18 / 21

## D. 管理層（→ 04）

- [ ] 過去 8 季指引命中 ≥ 6 季
- [ ] 溢價收購風險分數 < 3
- [ ] 有機成長 > 60%
- [ ] CEO 持股 > 3%
- [ ] 沒有 CEO / CFO 大量賣股（> 50% 持股）
- [ ] 薪酬連結 ROIC / FCF / TSR
- [ ] 資本配置分數 ≥ 7

## E. 價格（→ 05）

- [ ] 至少用 2 種以上估值方法
- [ ] DCF 終值占 EV < 75%
- [ ] **安全邊際 ≥ 自己風格的最低要求**（價值 25–35% / GARP 10–20% / 成長 0–10%）
- [ ] PEG < 2.0
- [ ] 風險報酬比 ≥ 3:1

## F. 風險（→ 06）

- [ ] 已跑過 bear case，強度 ≤ 4.0
- [ ] 能說出 3 個具體下檔風險，而且有量化
- [ ] 寫下論點失效條件（具體指標 + 門檻）
- [ ] 單一年度到期債 < 30%

## G. 題材股加檢（→ 08，只在標的屬於熱門題材時使用）

- [ ] 能說出它在供應鏈的哪一層（上游 / 中游 / 下游）
- [ ] 它所在的層級瓶頸分數 ≥ 7，或屬於二階受益者
- [ ] 利潤轉移方向是往它這一層移，不是離開
- [ ] 題材熱度 🔴 < 5 項（不是擁擠交易）
- [ ] EPS 上修幅度追得上股價漲幅
- [ ] 已寫下 3–5 個有門檻的 KPI 和確認訊號

---

## 快速判讀

| 結果 | 意義 |
|------|------|
| A + B + C 大多 ✅ | 好公司 |
| 再加上 E ✅ | 好公司 + 好價格 → 考慮買進 |
| A、B、C 好，E ❌ | 好公司但太貴 → 放觀察名單，等價格 |
| C 有任何 ❌ 是紅旗 | 先停下，深入查財報，再談其他 |
| B 的 ROIC < WACC | 成長也在毀滅價值，非常謹慎 |
| 題材股 G 區熱度 🔴 多 | 題材對、時機可能錯 → 改研究二階受益者 |
