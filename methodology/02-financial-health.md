# 02 — 財務體質

> 來源：`stock-eval.md` §2 Financial Health、§4 Key Ratios、Deep Financial Statement Analysis、ROIC/WACC；`fundamental-analysis.md` 比率速查。

**核心問題：公司在成長嗎？賺錢效率如何？資產負債表撐得住嗎？每投入一塊錢能創造多少價值？**

---

## 1. 成長與獲利

| 項目 | 看什麼 |
|------|--------|
| 營收 / 盈餘成長 | 3 年、5 年 CAGR |
| 三率 | 毛利率、營業利益率、淨利率 |
| 利潤率趨勢 | 擴張 / 穩定 / 壓縮 |
| 營收拆解 | 有機成長 vs. 併購 vs. 匯率影響 |
| 營收品質 | 經常性（訂閱/合約）vs. 一次性交易 |

### 成本結構

- COGS 占營收比例 5 年趨勢
- **SG&A 占營收比例上升但營收沒加速 → 效率惡化訊號**
- R&D 強度要依產業判斷（生技 vs. 消費品不同）
- 計算常態化盈餘時要剔除：重組費用、資產減損、處分資產損益、一次性稅務利益、訴訟和解

### 營運槓桿

- **增量營業利益率** = Δ營業利益 / Δ營收
- **DOL（營運槓桿度）** = 營業利益變動 % / 營收變動 %
- DOL > 3x：營收波動會被放大（上下都是）

## 2. 資產負債表與流動性

| 指標 | 公式 | 健康門檻 |
|------|------|----------|
| 流動比率 | 流動資產 / 流動負債 | > 1.5x 健康；< 1.0x 有流動性壓力 |
| 速動比率 | (流動資產 − 存貨) / 流動負債 | 越高越好 |
| D/E | 總負債 / 股東權益 | 越高風險越大 |
| 利息保障倍數 | EBIT / 利息費用 | > 3x（股利框架門檻） |
| Net Debt / EBITDA | 淨負債 / EBITDA | 見下表 |

**槓桿門檻（Net Debt / EBITDA）**

| 倍數 | 判定 |
|------|------|
| < 1.0x | 保守，資產負債表強健 |
| 1.0–2.5x | 中等，可控 |
| 2.5–4.0x | 偏高，密切監控 |
| > 4.0x | 高財務風險，彈性有限 |

產業差異（`dividend-analysis`）：科技 0–0.5x 算保守、> 2.0x 算吃緊；公用事業 2.5–4.0x 算保守、> 6.0x 算吃緊。

## 3. 營運資金週期

| 指標 | 公式 |
|------|------|
| DSO（應收天數） | 應收帳款 / (營收 / 365) |
| DIO（存貨天數） | 存貨 / (COGS / 365) |
| DPO（應付天數） | 應付帳款 / (COGS / 365) |
| **CCC（現金轉換週期）** | DSO + DIO − DPO |

**判讀**：
- CCC 下降 → 收錢更快、存貨更少，成長會帶來更多現金
- CCC 上升 → 成長在吃現金，是 FCF 的隱藏拖累
- **CCC 為負**（大型零售、訂閱制）→ 客戶先付錢，結構性現金優勢

**成長資金檢查**：每 $1 新營收需要的營運資金 = ΔNWC / Δ營收。**> 15% 時，即使獲利的公司也可能因快速成長而現金吃緊。**

## 4. 現金流

- 營業現金流（CFO）、自由現金流（FCF = CFO − Capex）、FCF 殖利率
- 區分**維護性資本支出** vs. **成長性資本支出**
- 資本支出連續多年低於折舊 → 投資不足（`financial-report-analyst` 紅旗）

## 5. DuPont 拆解：ROE 從哪裡來？

**三因子**：ROE = 淨利率 × 資產週轉率 × 權益乘數

**五因子**：ROE = 稅負比 × 利息負擔比 × EBIT 利潤率 × 資產週轉率 × 權益乘數

| ROE 主要來源 | 品質 | 範例 |
|--------------|------|------|
| 高**利潤率** | 最高品質、最可持續 | 精品、軟體 |
| 高**資產週轉** | 有效率但利潤薄，注意利潤率侵蝕 | 零售、經銷商 |
| 高**槓桿**（權益乘數 > 3x） | 報酬被放大、下檔也被放大 | 須評估債務可持續性 |

**ROE 下滑時，先找出是哪個因子在惡化再下結論。**

## 6. ROIC / WACC / EVA：價值創造的最終檢驗

### ROIC

```
ROIC = NOPAT / Invested Capital
NOPAT = EBIT × (1 − 有效稅率)
Invested Capital = 股東權益 + 總負債 − 現金
```

### WACC

```
WACC = (E/V) × Re + (D/V) × Rd × (1 − T)
Re（CAPM）= Rf + β × (Rm − Rf)
  Rf：10 年期美債殖利率
  β：5 年月資料 vs. S&P 500
  ERP：約 5–6%
```

### EVA

```
EVA = (ROIC − WACC) × Invested Capital
```

| 狀態 | 意義 |
|------|------|
| ROIC > WACC | **創造價值**：每一塊錢投入賺得比成本多，強正面訊號 |
| ROIC = WACC | 經濟上打平 |
| ROIC < WACC | **毀滅價值**：重大警訊 |

**要看 4 年趨勢**：利差擴大 = 價值創造改善；利差收斂 = 惡化。

## 論點失效條件（範例）

- 看多失效：營收成長連續 2 季降到 5% 以下，**且**毛利率收縮 > 200bps
- 看空失效：營收重新加速到 > 15%，**且**利潤率恢復擴張
