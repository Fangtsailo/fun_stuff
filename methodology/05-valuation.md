# 05 — 估值

> 來源：`stock-valuation.md`（主）、`stock-eval.md` §3 Valuation Metrics、DCF Framework、Margin of Safety。

**核心問題：好公司不等於好投資。現在的價格比內在價值便宜多少？**

原則：**絕不只用一種方法。** 用 DCF、同業比較、EV/EBITDA、P/E、剩餘收益交叉驗證；方法之間落差大時，那個落差本身就在透露市場預期。

---

## 1. 選對估值方法

| 方法 | 適用 | 避免 |
|------|------|------|
| DCF | 成熟、FCF 為正 | 未有營收、銀行、REITs |
| 同業比較 CCA | 任何有可比上市公司的標的 | 沒有好的可比公司 |
| EV/EBITDA | 資本密集產業 | 輕資產、高 SBC 科技股 |
| P/E | 盈餘穩定 | 虧損公司 |
| P/S | 營收階段的成長股 | 成熟高毛利公司 |
| 剩餘收益 RI | 金融業、帳面價值有意義 | 輕資產公司 |
| DDM | 配息價值股 | 成長股 |
| NAV | 不動產、控股公司 | 營運型公司 |

---

## 2. DCF（現金流折現）

### 步驟

1. **基期**：TTM 營收、CFO、Capex、FCF、SBC、稀釋股數、淨負債
2. **真實經濟 FCF = FCF − SBC**（SBC 是真實成本）
3. **三情境 10 年預測**：

| | Bull | Base | Bear |
|--|------|------|------|
| 機率 | 20% | 60% | 20% |
| 營收 CAGR 1–5 年 | 較高 | 共識 | 較低 |
| FCF 利潤率 | 擴張 | 穩定 | 壓縮 |
| WACC | 較低 | 基準 | 較高 |
| 終值成長 g | 2.5% | 2.0% | 1.5% |

4. **終值**：`TV = FCF₁₀ × (1 + g) / (WACC − g)`，g 通常 2–3%，**絕不可 g > WACC**
5. **折現**：EV = Σ PV(FCF) + PV(TV)；股權價值 = EV − 淨負債；每股價值 = 股權價值 / 稀釋股數
6. **機率加權內在價值** = 20% × Bull + 60% × Base + 20% × Bear

### 營收成長的多重錨點

分部門預測、歷史 3/5/10 年 CAGR、分析師共識（1–3 年）、管理層指引、**產業成長率當上限**（公司不可能永遠比產業長得快）、前 5 年高成長、後 5 年遞減至終值成長。

### WACC 參考範圍

| 風險 | WACC |
|------|------|
| 低（公用事業、大型必需消費） | 6–8% |
| 中（大型科技、成熟成長股） | 8–11% |
| 高（小型、新興市場、景氣循環） | 11–15% |
| 極高（早期、困境、未有營收） | 15–20%+ |

### 敏感度表（WACC × g）

- **整張表都有安全邊際** → 高度確信低估
- **只有少數格子有** → 估值高度依賴特定假設
- **沒有任何格子有** → 所有合理情境下都偏貴

### DCF 常見陷阱

1. 把近期高成長率外推太久
2. **終值占 EV > 70–75%** → 比較像投機而非分析，要加大壓力測試
3. WACC 太低、忽略小型股溢價
4. 景氣循環股用高峰 FCF 當基期
5. 忽略 SBC
6. 只做單一情境
7. 忽略快速成長公司吃掉的營運資金

## 3. 同業比較（CCA）

- 選 5–8 家：同產業、同商業模式、類似成長、市值在 0.5–2.0 倍內
- 比較 EV/Revenue、EV/EBITDA、Forward P/E、EV/FCF，各 25% 權重
- 用**同業中位數**乘上目標公司數據得到隱含價格
- 調整：成長、利潤率、資產負債表較佳 → +10–20%；規模小、流動性差、基本面弱、有法規疑慮 → −10–25%

---

## 4. 倍數參考

| 指標 | 看法 |
|------|------|
| P/E | 與自身 5 年歷史、同業、S&P 500 比 |
| **PEG** | < 1.0 低估；> 2.0 昂貴 |
| EV/EBITDA | 與歷史平均、同業中位數比 |
| Justified P/B（金融股） | 1 + (ROE − Ke) / (Ke − g) |

`stock-eval` 要求每個倍數都要與「現在 / 1 年前 / 5 年平均 / 產業平均」四欄比較。

---

## 5. 足球場圖（Football Field）

把所有方法的 Bear / Base / Bull 放在一起，加上 52 週區間與分析師目標價，**再依適用程度加權**得出綜合內在價值。

---

## 6. 安全邊際

```
安全邊際 = (內在價值 − 市價) / 內在價值 × 100%
```

| 狀態 | 判定 |
|------|------|
| 折價 > 30% | 極具價值，安全邊際強 |
| 折價 10–30% | 合理進場 |
| 折價 0–10% | 價格合理，安全邊際有限 |
| 溢價 10–30% | 略貴，需要成長信念 |
| 溢價 > 30% | 昂貴，價格反映完美情境 |
| 溢價 > 50% | 非常昂貴，倍數壓縮風險高 |

**不同投資風格的最低要求**：深度價值 25–35%；GARP 10–20%；成長股 0–10%（或對高品質成長股接受小幅溢價）。

---

## 7. 風險調整後預期報酬

```
預期報酬 = Σ (情境機率 × 情境報酬)
風險報酬比 = Bull 上檔 / Bear 下檔
```

**好的投資通常有 3:1 以上的風險報酬比。**

---

## 8. 與分析師共識比較

- 模型價值 > 共識：市場可能低估成長 / 利潤率
- 模型價值 < 共識：市場可能過度樂觀
- 落差大：找出關鍵假設差異在哪

---

## 論點失效條件（範例）

- 看多失效：更新假設後內在價值下降 > 20%，或相對同業的倍數壓縮惡化
- 看空失效：5 種估值方法同時顯示 > 20% 上檔
