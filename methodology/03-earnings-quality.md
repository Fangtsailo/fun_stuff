# 03 — 盈餘品質與財報鑑識

> 來源：`stock-eval.md` Quality Scoring Framework（Piotroski、Earnings Quality）；`financial-report-analyst.md` Phase 1–8；`bear-case.md` §3 會計紅旗。

**核心問題：公司報的獲利是真的嗎？現金有沒有跟上？財報裡藏了什麼？**

框架原話：「現金流量表是最難操縱的，是真相的揭露者。」

---

## 1. Piotroski F-Score（0–9）

9 個二元條件，通過得 1 分。

| # | 類別 | 條件 | 通過標準 |
|---|------|------|----------|
| 1 | 獲利 | ROA > 0 | 本年度 ROA 為正 |
| 2 | 獲利 | CFO > 0 | 營業現金流為正 |
| 3 | 獲利 | ROA 變化 | ROA 較去年改善 |
| 4 | 獲利 | 應計品質 | CFO / 總資產 > ROA（現金盈餘 > 帳面盈餘） |
| 5 | 槓桿 | 槓桿變化 | 長期負債 / 平均資產下降 |
| 6 | 流動性 | 流動比率變化 | 流動比率改善 |
| 7 | 資金來源 | 無新股發行 | 過去一年沒有增發 |
| 8 | 效率 | 毛利率變化 | 毛利率擴張 |
| 9 | 效率 | 資產週轉變化 | 資產週轉率改善 |

| 分數 | 解讀 |
|------|------|
| 8–9 | 財務強健，高品質候選 |
| 5–7 | 普通 |
| 0–2 | 財務弱，惡化風險高 |

---

## 2. 盈餘品質指標

| 指標 | 公式 | 好 | 壞 |
|------|------|----|----|
| 應計比率 | (淨利 − CFO) / 平均總資產 | 低或為負 | 高 |
| 現金轉換率 | CFO / 淨利 | 持續 > 1.0x | < 0.7x 可能灌水 |
| FCF 轉換率 | FCF / 淨利 | > 80% | 明顯低於淨利 |
| SBC 占營收 | 股權酬勞 / 營收 | < 5% | > 5% 是真實稀釋 |

另外要檢查：
- 非經常性項目剔除後的常態化盈餘
- 營收認列風險：塞貨（channel stuffing）、bill-and-hold、激進的遞延收入認列

## 3. 財報閱讀八階段（`financial-report-analyst`）

### Phase 1 — 文件定位

| 檢查 | 警訊 |
|------|------|
| 會計師意見 | 非無保留意見 |
| **更換會計師** | **重大紅旗，立即調查** |
| 申報日期 | 延遲申報 |
| 重編 | 前期數字重編 |

### Phase 2 — MD&A 批判性閱讀

- 管理層說的成長動能是可持續還是一次性？
- 有機成長 vs. 併購要明確拆開
- 高毛利 / 低毛利產品組合變化
- Backlog、RPO、遞延收入趨勢
- **指引從具體數字變成方向性用語（「我們預期持續成長」）= 信心下降的重要訊號**

利潤率討論的紅旗：
- Non-GAAP 排除項成長快於 GAAP 費用
- 毛利率壓縮只說「產品組合」不講細節
- 營運槓桿的說法沒有反映在實際營業利益率上

### Phase 3 — 三表深入

**損益表**
- 營收認列政策有沒有變？
- **應收帳款成長快於營收（DSO 拉長）→ 塞貨訊號**
- 遞延收入成長（好，客戶預付）或萎縮（壞）
- 稅率異常低 → 通常是一次性利益，要常態化

**資產負債表紅旗**
- 商譽 > 總資產 30% 且無明確併購理由
- 應收帳款成長 > 營收成長 2 倍
- 需求走弱時存貨卻在堆積
- 表外租賃負債（ASC 842）
- 退休金缺口藏在 AOCI

**現金流量表紅旗**
- FCF 明顯低於淨利
- 營運資金大量堆積吃掉現金
- SBC > 營收 5%
- Capex 多年低於折舊

### Phase 4 — 風險因子（10-K Item 1A）

**比較本期與前期**：新增了哪些風險？移除了哪些？哪些被擴寫或排序往前移？

最高優先的風險類別：
- 法規 / 訴訟：政府調查、重大訴訟
- 客戶集中：單一客戶 > 10% 營收
- 點名特定競爭者為存亡威脅
- **Going Concern（持續經營疑慮）→ 立即紅旗**
- 債務契約違約風險
- 資安事件（8-K Item 1.05）

### Phase 5 — 會計政策與附註

「附註裡是管理層不希望你注意的東西。」

- 關鍵會計估計：營收認列、商譽減損測試、SBC 假設、遞延所得稅資產（新增備抵 = 警訊）、或有負債、退休金假設
- **關係人交易**：需加強審查
- **部門重組**：部門被合併常用來隱藏表現差的業務；商譽在部門間移轉可延後減損

### Phase 6 — 管理層語氣

每個段落 1–5 分評語氣，並與前期比較。

避險用語分級：
- 一般：「我們相信 / 預期」
- 不確定性升高：「我們無法保證」
- 接近危機：「重大不確定性」
- 壞消息用被動語態、好消息用主動語態
- 「逆風」「充滿挑戰的環境」「疲軟」出現頻率增加

### Phase 7 — 季度比較（10-Q）

同時比 YoY 與 QoQ：

| 型態 | 定義 |
|------|------|
| 加速 | 季增改善 + 年增超標 |
| 穩定 | 季增持平 + 年增符合 |
| 減速 | 季增不如預期 + 年增仍正 |
| 惡化 | 季增、年增都不如預期 |

### Phase 8 — 內部人動向

見 [04-management.md](04-management.md)。**CFO 離職特別值得注意。**

## 4. 會計品質評分（0–21）

每項 0–3 分：

| 項目 |
|------|
| 營收認列清晰度 |
| Non-GAAP 調節品質 |
| FCF 轉換率 |
| 營運資金趨勢 |
| 附註透明度 |
| 會計師意見 |
| 關係人交易 |

| 總分 | 解讀 |
|------|------|
| 18–21 | 高品質 |
| 12–17 | 普通 |
| < 12 | 需進一步審查 |

## 5. 鑑識會計視角（`bear-case` §3）

參考 Hindenburg / Muddy Waters / Beneish 的做法：

- Non-GAAP 與 GAAP 差距擴大；「一次性」費用年年出現；SBC 被排除在調整後指標外
- 淨利上升但 CFO 落後
- **庫藏股只是在抵銷 SBC 稀釋，股數沒有真的減少**
- DSO / DIO 上升（Beneish DSRI / SGI 訊號）
- 會計師更換、重編、延遲申報、內控重大缺失、CFO 異動

## 論點失效條件（範例）

- 看多失效：會計師出具持續經營疑慮，或宣布重大重編
- 看空失效：新會計師排除所有疑慮，且重編結果有利
