**核心問題：這個數字是哪裡來的、哪一天的、能不能當成立依據？**

---

## 1. 硬框（每份週報頁首都要有）

1. **分析師草稿／需本人拍板**；**不下單**；**不構成投顧**。〔技能§1.1〕
2. **不問、不盤點**本人資產、現金、借款、維持率、曝險；稿內不列任何資產數字。〔技能§1.2〕
3. **預設不叫財務／策略角色**；本人明說「決定要買」才請他們對齊資金與既有持股／借款框。〔技能§1.3〕〔甲 角色邊界〕
4. **既有拍板不得推翻**；只在規則文字裡處理，**公司名旁不附**「觀察」「不加碼」等狀態字樣（除非本人要求）。〔技能§1.4〕
5. **不得用資金門／估值門把個股候選砍光**。個股候選是熱門板塊裡尚未挑定的股票，不是第一段的候選板塊。〔技能§1.5〕
6. 目標價、法人目標價只當**論述溫度計**，不是買賣價或指令。〔技能§1.6〕

## 2. 錨日

1. 一律用「**交件日往回最近一個有交易的日子**」收盤；休市／週末寫明原因。所有價格、倍數、法人窗都對齊錨日。〔技能§0.3〕
2. 休市日用交易所當日無資料的回應確認，寫進來源表。〔技能§5.1〕
3. 範例：10/04（週日）交件 → 錨日 **2026-10-02**（10/03–10/04 週末）。〔10/04稿 頁首〕

## 3. 來源分級（本流程實際使用的標記）

| 標記 | 意思 | 能不能讓訊號成立 | 出處 |
|---|---|---|---|
| **原檔** | 只有兩種：**公開資訊觀測站（MOPS）**（財報、重大訊息、法說會簡報檔）、**公司官方投資人頁面**（財報、法說簡報、逐字稿、影音） | 第 3 類只有原檔且分級「明確」才成立 | 〔財報規格〕二.1；〔技能§2 第3類方法 1〕 |
| **官方** | 交易所市場資料：TWSE／TPEx 個股日成交、本益比、三大法人日報（T86／TPEx 三大法人） | 流向訊號用官方 | 〔技能§5.1〕 |
| **二手** | 富邦 DJ、媒體、券商與研究機構整理、共識彙整、第三方網站 | **只當佐證**，不能單獨讓第 3 類成立；要降信心 | 〔財報規格〕二.3、四；〔技能§9.4.2〕 |
| **海外** | 美股上下游財報／法說／資本支出 | 只在與板塊有明確連動時查，不取代台灣來源 | 〔財報規格〕二.4 |
| **估計** | 研究端估算（例：題材營收純度） | 要寫依據 | 〔技能§8.8〕 |
| **分類假設** | 研究端貼上的類別（例：「AI 明確」「純景氣循環」） | 不是數字，也不是展望分級；假設與已驗證分開 | 〔清單〕頁首「定性標示」 |
| **缺件** | 該取而取不到的財報／法說原檔 | 不成立；寫缺哪份、查過哪些來源、影響哪個結論 | 〔財報規格〕四；〔技能§9.4.1〕 |
| **資料不足** | 板塊層：代表公司**過半缺件**，或流向缺超過 2 天 | 不算成立、也不算不成立 | 〔技能§9.4.3〕〔02 §2、§4〕 |
| **標缺** | 一般性缺資料 | 不擋交件；有替代法就寫替代法並降信心 | 〔技能§9.1–9.2〕 |

- **法說行事曆**（TWSE／TPEx）只用來找日期與是否有開，**不當內容來源**。〔財報規格〕二.2
- **法人數字一律標單位（股／張）與來源（官方／估計）**；週報用官方三大法人日報（原始單位股），個股詳版與 pool 用富邦 DJ 法人持股頁（張、估計），兩者並存不互相取代。〔技能§5.1〕
- **週報法人一律寫「張」**：官方日報的股÷1,000 四捨五入成整數張；週報 §1 固定寫一行「法人資料原始單位為股，已換算為張」。〔09 裁決 5〕
- 單位要標（股 vs 張、仟元 vs 億）。〔技能§5.1〕

### 3.1 週報來源標籤（上表 → 週報寫法）〔09 裁決 4〕

週報只用四個來源標籤，定義同 [09](09-report-format.md) §3.4：

| 上表標記 | 週報寫法 |
|---|---|
| 原檔（公開資訊觀測站、公司官方投資人頁面） | 【一手】 |
| 官方（證交所／櫃買等官方統計） | 【官方】 |
| 二手（媒體、富邦 DJ、潮汐等） | 【二手】 |
| 缺件 | 【缺件】 |
| 海外 | 照實際來源歸到上面四種；仍只當佐證、不取代台灣來源 |
| 估計 | 數字前加 `~`，不另設標籤；依據照寫 |
| 分類假設、其他非數字判斷 | 附上依據的來源標籤。展望分級的「定性」不是這一種 |
| 資料不足、標缺 | 狀態，不是來源標籤；寫法不變 |

## 4. 不發明數字

1. 抓不到、來源不穩、只有二手 → 寫「標缺」並說明**缺什麼、影響哪個結論**；**不用二手數字冒充原檔**。〔技能§9.1〕
2. 每份稿列「**標缺前三**」，其餘列「（次）」。〔技能§9.3〕
3. 時間一律 Asia/Taipei 並標日期；每個數字標來源與日期；「假設」與「已驗證」分開。〔技能§8.4–8.5〕
4. **領先 vs 落後**：月營收、營收創高多屬落後指標；論點以未來 1～2 季轉折為主，寫明所用指標屬領先或落後。〔技能§8.7〕

## 5. 抓取紀律（被擋就停）

1. **被防護擋住不自動改用瀏覽器**（本人 2026-09-30 拍板）：遇到 Radware、Incapsula 等防護 → 直接標「缺件」並註明原因，等本人要求才補。〔技能§9.4.1a〕
2. 抓網頁的做法：**單線、隨機間隔、被擋就停**；不換 IP、不改 UA、不開瀏覽器。〔本人慣例，2026-10-06 交辦清單〕；實例見 `/workspace/tide-tw-板塊成分股對照-2026-10-05.md` 第 8 行（單線、每次隔 5–15 秒亂數）。
3. **潮汐（tide-tw）不進週報**；需要時手動對照，標【二手】。（本人 2026-10-06 拍板）
4. 範例（10/04）：TWSE T86 10/01 被安全攔截 → 標缺；廣達(2382) IR 被 Radware 擋、奇鋐(3017) IR 被 Incapsula 擋 → 缺件、未自動瀏覽器補抓。〔10/04稿 還缺 2、4〕
