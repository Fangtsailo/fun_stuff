# 一頁式檢核表：週報交件前

> 快速版。每項打 ✅ / ⚠️ / ❌。細節看各編號檔；本檔只摘現行規則，不新增。

## A. 頁首與硬框（→ 00）

- [ ] 寫了日期、性質（分析師草稿／需本人拍板）、本輪不做、錨價日（含休市／週末原因）
- [ ] **不下單、不構成投顧**；無資產數字；無買賣／加減碼命令句
- [ ] 公司名旁沒有「觀察」「不加碼」等狀態字樣（「長抱論述弱」除外）
- [ ] 來源標籤只用【一手】【官方】【二手】【缺件】（估計數字加 ~、分類假設與其他非數字判斷附依據標籤）；法人一律寫張，§1 註明「法人資料原始單位為股，已換算為張」

## B. 板塊與訊號（→ 01、02）

- [ ] 用的是現行清單 rev4（19 板塊），本期增刪已寫明
- [ ] 總表涵蓋**全部**清單板塊；新聞與流向標成立／不成立／資料不足；財報法說另可標未完成（僅第一段）或「沿用上次：」（不計入成立類數）
- [ ] 新聞成立＝5～10 日內 ≥2 家媒體正面報導且點到 ≥2 家代表公司或整個題材
- [ ] 流向成立＝外資或投信 20 日合計淨買超且近 5 日同一方淨買超；20 個交易日照日曆、缺日標缺不往前補、缺 >2 天標資料不足
- [ ] 熱門＝至少兩類；觀察＝只一類（寫哪一類、不挑股）；沒有硬湊
- [ ] 沒有把漲幅、成交量、月營收年增當成立依據

## C. 第 3 類原檔（→ 03）

- [ ] 「明確」都附頁碼（或 MOPS 公告日期時間＋序號）與原文摘錄
- [ ] 沿用的判定都標了日期
- [ ] 二手只當佐證；缺件寫明原因與查過的來源；被防護擋住未自動用瀏覽器
- [ ] 門檻只算展望相關文件（設備／廠房／資產取得公告列附錄筆數）
- [ ] >15 份時：第一段候選表含判定欄（熱門／觀察）、文件數、成立類別、未讀清單，§7 不適用；完整版沒有留下「未完成」；沒深讀的寫「沿用上次：」並在待補列本期未讀
- [ ] 實際引用的原檔已存 `/workspace/財報法說原檔/{年月}/` 並入索引

## D. 入選（→ 04、05）

- [ ] 每熱門板塊 1～2 檔；第 2 檔有一句理由
- [ ] 完整版 5 小段照 09 §5（事實表第一列板塊角色＋純度＋供應鏈地位；正方第 1 點＝為何最佳、反方第 1 點＝主要風險；不畫價量疊圖）；為何沒選同板塊其他檔寫在 09 §3「落選」行，沒有寫「落選：無」
- [ ] 長抱標強／條件／弱（強＝結構驅動且清單無加註；條件＝一個可核對前提；弱＝清單已加註，或只剩週期／方向分歧／論述零碎）；條件寫明前提
- [ ] 精簡版 4 行：為什麼熱一句、弱在哪、價格行「錨日收盤 NT$x｜合理帶 NT$y–z」或「錨日收盤 NT$x｜未估值：原因」（錨日收盤：官方→其他官方→【二手】附來源日期→標缺）、標缺
- [ ] 有寫估值的：合理帶、偏便宜帶、中樞三個台幣數字＋來源＋錨日；與同週 pool 同一套

## E. 交件（→ 07、09）

- [ ] 章節照 09 §5 骨架（Data & Sources、結論先講、§1–§8、本次未驗證 / 待補、附錄），不適用的保留標題寫「不適用：原因」；§6 總表列出全部入選；細項照 09 §9 自查
- [ ] 聊天短版照 09 §7：列全部入選，每檔一行（公司名(股號)、板塊、長抱標註、一句理由）＋詳版路徑＋PR 連結
- [ ] 還缺＋標缺前三＋（次）
- [ ] 附錄：例行公告筆數＋資料來源（類型、日期窗、檔案路徑）
- [ ] 全份沒有價量疊圖（點名深挖才另走模式 B）
- [ ] 拆兩段時：`_part1` 保留，完整版 Data & Sources 框有第一段路徑；第一段未讀清單每份一行（公司名(股號)｜文件類型｜日期｜板塊｜來源標籤；先板塊、再日期由新到舊）
- [ ] 正式版進 repo `analysis/weekly/`；brief／handoff 底稿另存

## 快速判讀

| 狀況 | 怎麼辦 |
|---|---|
| 零個板塊達兩類 | 照寫「本期無板塊達兩類交叉」 |
| 展望相關新文件 >15 份 | 20:00 交第一段；本人挑完再交完整版 |
| 官方價被擋 | 標缺；不繞過 |
| 本人點名某檔 | 該檔走模式 B（含價量疊圖，見 06） |
