# 08 — 熱門題材分析

> 來源：`industry-map.md`（主）、`sector-analysis.md`、`bear-case.md`、`catalyst-calendar.md`、`thesis-tracker.md`。
> §7–§9 標示「補充」的部分**不是 InvestSkill 原生內容**，是為了補足它沒有的熱度 / 擁擠度 / 生命週期判斷而加的經驗法則。

**核心問題：這個題材的錢最後會流到誰手上？現在進場是太早、剛好，還是已經擠滿人？**

## 1. 界定範圍

輸入可以是三種：

| 類型 | 範例 | 要畫什麼 |
|------|------|----------|
| 題材 / 產品 | AI 算力、電動車、GLP-1 減肥藥 | 整條鏈 |
| 單一股票 | NVDA | 它周圍的鏈，再定位它 |
| 某一層 | 記憶體、晶圓代工 | 該層 + 上下游鄰居 |

先寫清楚邊界：鏈從哪裡開始（礦石？晶圓？），到哪裡結束（付錢的終端用戶）。

---

## 2. 畫供應鏈

```
上游（稀缺投入、設備、IP）→ 中游（整合、製造、平台）→ 下游（通路、終端需求）

原料 → 設備 → 零組件 → 整合商/OEM → 平台 → 通路 → 終端用戶
```

每一層記錄：

| 欄位 | 說明 |
|------|------|
| 位置 | 上游 / 中游 / 下游 |
| 代表股票 | 2–5 檔 |
| 集中度 | 獨占 / 寡占 / 分散 |
| 目前獲利 | 高 / 低 / 循環 |

每條連線記錄：依賴強度（唯一供應 / 多來源 / 大宗商品），以及買方能否往上游整合、賣方能否往下游整合。

**位置決定個性**：上游通常循環性強、定價權看稀缺度；下游看品牌與用戶黏著。

---

## 3. 瓶頸分析（最容易找到超額報酬的地方）

```
瓶頸分數（0–10）= 下列 4 項平均，每項 0–10
- 供應商稀缺度   供應商越少越高
- 可替代性       沒有替代方案越高
- 轉換成本/前置期 認證新供應商越久越高
- 需求彈性       整條鏈少了它就停擺越高
```

高分層 = **收過路費的人**：不管下游誰贏都能賺。經典案例：ASML（EUV 唯一供應商）、台積電（先進製程）、NVDA + CUDA（硬體加軟體鎖定）。

要明確寫出：
- 瓶頸**現在**在哪裡
- 瓶頸**能持續多久**：有沒有第二供應商在認證、客戶自製、新架構繞過
- 「軍火商」論點：瓶頸層通常不管下游誰勝出都會贏

---

## 4. 利潤轉移推演

利潤池不是固定的。

- **現在**：哪一層賺厚利、哪一層只是薄利轉手？
- **稀缺轉移**：今天的瓶頸會被競爭或過度擴產打掉，新瓶頸出現在別處（例：算力稀缺 → 電力 / 數據稀缺；硬體利潤 → 軟體 / 服務）
- **方向**：往下游（硬體商品化，利潤流向平台與應用）還是往上游（誰控制新的稀缺投入）
- **預測**：點名 1–3 年內會吃到新增利潤的層級，以及**確認訊號**（產能開出、標準成形、某投入品變稀缺）

---

## 5. 供應鏈風險

- 單一來源 / 單一地區瓶頸（例：台灣晶圓代工集中、稀土加工集中）
- 地緣政治：出口管制、關稅、制裁可能切斷某條連線
- 連鎖效應：上游一個節點出事，下游會影響多遠
- **長鞭效應**：需求訊號往上游放大，先超額下單再變庫存過剩（記憶體、零組件特別明顯）
- 某一層對單一下游客戶銷售 > 30%，會繼承那個客戶的命運

---

## 6. 產出標的清單

| 類型 | 意義 | 操作屬性 |
|------|------|----------|
| 瓶頸層 | 對整個題材收過路費 | 核心 / 軍火商 |
| 直接受益者 | 最明顯的受益者 | 共識多頭 |
| **二階受益者** | 賣鏟子給贏家，非純題材股 | **市場覆蓋不足，框架特別強調** |
| 被夾擊者 | 上下游都強勢 | 避開 / 放空候選 |
| 選擇權型 | 利潤轉移過來時的便宜曝險 | 投機 |

清單交給下一步：`stock-screener` 排名 → `competitor-analysis` 檢查護城河 → `bear-case` 壓力測試共識贏家。

### 範例：AI 算力

- 瓶頸：設備（ASML EUV）、GPU（NVDA + CUDA）
- 現在的利潤池：GPU 與晶圓代工；雲端大廠在吸收龐大資本支出；模型公司大多虧損
- 轉移論點：加速器供給追上後，稀缺轉向**電力、網通、HBM 記憶體**；價值流向變現既有算力的推論軟體
- 確認訊號：加速器交期恢復正常
- 避開：沒有數據護城河的應用層公司

## 7. 產業輪動與市場預期

### 產業動能排名（`sector-analysis`）

11 個 GICS 產業各在 4 個面向排 1–11 名，取平均：

| 面向 | 看什麼 |
|------|--------|
| 3 個月報酬 | 相對強弱 |
| EPS 上修廣度 | 上修前瞻 EPS 的分析師比例 |
| 前瞻 P/E vs. 10 年平均 | 折價得高分 |
| 分析師情緒 | 買進減賣出評等比例 |

| 綜合排名 | 動作 |
|----------|------|
| 1–3 | 大幅加碼 |
| 4–5 | 小幅加碼 |
| 6–7 | 中性 |
| 8–9 | 減碼 |
| 10–11 | 避開 |

動能型策略可改權重：價格 40% + EPS 上修 30% + 估值 20% + 情緒 10%。

**限制**：GICS 是傳統產業分類，題材（如 AI）通常橫跨多個產業，所以要搭配 `industry-map` 使用。

### 價格已反映多少（`bear-case`）

- **反向 DCF**：現價隱含未來 10 年要多少成長和利潤率？合理嗎？
- 倍數比自身 5 年區間、同業高幾倍？
- 題材的成長是**持久的**，還是**一次性 / 循環性**的爆發？

## 8. 驗證題材：催化劑與 KPI

### 催化劑（`catalyst-calendar`）

列出未來 90 天會產生新證據的事件，例如：大廠資本支出指引、龍頭法說會、產品發表、法規決定、解禁、指數調整。**多個催化劑集中在同一段時間 = 波動放大的窗口。**

### 題材論點（`thesis-tracker`）

用一段話回答三件事：
1. **必須發生什麼**（商業機制，不是「股價會漲」）
2. **市場錯在哪**：為什麼你看得到、邊際買家看不到
3. **為什麼是現在**

測試：一個理性的空頭讀完，能不能精確知道要反駁哪一點？

再設 **3–5 個有門檻的 KPI**（優先用財報數字），例如：

| KPI | 門檻 | 為什麼重要 |
|-----|------|------------|
| 資料中心營收 YoY | ≥ 40% | 估值假設雲端大廠資本支出持續成長 |
| 毛利率 | ≥ 70% | 定價能力的足跡 |
| 淨現金 | > 0 | 排除景氣反轉時的資產負債表壓力 |

允許一個估值 KPI，用來偵測「論點對但已完全反映」的狀態。

**狀態判定**：
- 2 個以上 KPI 跌破門檻 → BROKEN（不可加碼）
- 1 個跌破 → WEAKENED（提前檢查、不加碼）
- 全部在門檻內且資料是新的 → INTACT

**事前驗屍**：寫一段「12 個月後這個部位虧了 40%，原因是……」。如果寫出的原因沒有任何觸發條件能抓到，就補一條。

## 9. 熱度與擁擠度（補充，非 InvestSkill 原生）

InvestSkill 沒有題材層級的泡沫判斷。以下是補充的觀察項，每項打 🟢 冷 / 🟡 溫 / 🔴 熱。

| 面向 | 觀察項 | 🔴 過熱訊號 |
|------|--------|-------------|
| 資金 | 題材 ETF 淨流入、新題材 ETF 發行數 | 連續數月大量流入、短期內多檔新 ETF 上市 |
| 散戶 | 題材股短天期買權成交量、散戶論壇聲量 | 價外短天期 call 爆量 |
| 媒體 | 新聞 / 社群提及次數 | 主流財經媒體頭版、非財經媒體也在談 |
| 企業行為 | 法說會提到題材關鍵字的公司數 | 與題材無關的公司也在蹭（改名、改簡報） |
| 資本市場 | 題材相關 IPO、增資、可轉債 | 大量發行（內部人趁高價籌資） |
| 估值離散 | 題材股與大盤的估值差距 | 無獲利公司估值與龍頭相當 |
| 相關性 | 題材股彼此的股價相關性 | 好壞公司一起漲跌（市場不再區分品質） |
| 空方 | 題材股放空比例（`short-interest`） | 空單極低，已無人敢空 |
| 機構 | 13F 機構持股集中度（`institutional-ownership`） | 大量基金重倉同一批股票 |

**判讀**：🔴 ≥ 5 項 → 擁擠，新資金進場的風險報酬比差；這時候 `industry-map` 裡的二階受益者通常比共識贏家更值得研究。

### 題材生命週期（補充）

| 階段 | 典型訊號 | 策略傾向 |
|------|----------|----------|
| 萌芽 | 只有產業內部在談；營收尚未出現；估值未反映 | 研究瓶頸層，小部位 |
| 確認 | 龍頭營收 / EPS 開始大幅上修；分析師陸續覆蓋 | 核心部位建立期 |
| 擴散 | 資金從龍頭擴散到二、三線與二階受益者 | 找二階受益者；龍頭檢查估值 |
| 過熱 | §9 多數 🔴；無關公司也蹭題材；大量籌資 | 不追高，收緊觸發條件 |
| 幻滅 | 龍頭指引不如預期、長鞭效應開始、瓶頸被打破 | 依 `thesis-tracker` 狀態執行 |

**判斷階段的關鍵**：比較「股價漲幅」與「EPS 上修幅度」。股價漲得比 EPS 上修快很多 → 在往過熱走；EPS 上修追得上股價 → 仍在確認或擴散期。

## 論點失效條件（範例）

- 看多失效：瓶頸被打破（第二供應商通過認證、客戶自製），或利潤轉移離開你押注的層級
- 看空失效：該層重新建立持久瓶頸，或出現對它有利的新稀缺投入
