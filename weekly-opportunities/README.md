## 一句話總結

**週投資機會 = 19 個固定板塊 × 三類訊號（新聞 5～10 日、外資或投信 20 交易日、財報／法說原檔「明確」），至少兩類交叉才算熱門；每個熱門板塊挑 1～2 檔「基本面＋題材」代表，長抱弱只標註不排除；價格沿用 brief／pool 價帶；拿不到就標缺，不發明、不繞過。**

## 適用範圍

- **適用**：模式 A 的**週報**（每週日 20:00）。
- **只在對照時提到**：月報（多「與上期對照」、被刪板塊輕量複檢、第 3 類全部複查）。
- **不在本資料夾展開**：模式 B（指定個股六段）、模式 C（優質 pool），只寫週報會用到的部分（點名後走模式 B、估值沿用 pool 價帶）。

## 四個核心原則

1. **交叉才算熱**：單一訊號只進觀察名單；漲幅、成交量不是訊號；不硬湊、不降門檻。（02）
2. **只有原檔的數字算數**：MOPS 與公司官方投資人頁面才是原檔；分級「明確」才成立；二手只當佐證。（03）
3. **長抱只標註、不排除**：論述弱照選，寫出弱在哪；不用資金或估值門砍光候選。（04）
4. **缺了就標缺**：不發明數字、不用二手冒充原檔、被防護擋住不自動開瀏覽器。（00）
