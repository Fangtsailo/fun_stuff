# 09 — 個股分析報告格式規範

> 所有 `analysis/` 下的個股報告都必須照這份格式寫。目的：任兩份報告可以逐節對照，同一個數字永遠在同一個位置。
> 僅供學習用途，非投資建議。

---

## 1. 硬規則（違反任一條就不算完成）

1. **章節編號固定**：所有報告都有完全相同的章節與編號。不適用的章節**保留標題**，內文寫「不適用：原因」，不可刪除或改號。
2. **必填分數一個都不能少**：見 §3 必填分數表。每一項是這次抓取算出的數字。只有截至 As of、該項的公開文件還不存在時，才寫「未評估（預設 5.0）」，並在待補清單寫出那份還沒公布的文件。
3. **單位統一**：見 §4。
4. **符號統一**：✅ ⚠️ ❌ 只用在判定；🟢 🟡 🔴 只用在題材熱度。
5. **開頭與結尾固定**：開頭是 Data & Sources 區塊（00），結尾是「本次未驗證 / 待補」。

---

## 2. 檔名與存放位置

```
analysis/{股票代號}_{英文簡稱}.md
例：analysis/2330_TSMC.md
```

- 股價日期寫在開頭 Data & Sources，不寫進檔名
- 一家公司只留這一檔。重跑時覆蓋同一路徑，並更新 Data & Sources 的產出日期與股價日期

## 4. 單位與寫法

| 項目 | 規定 | 不要寫 |
|------|------|--------|
| 金額 | **NT$億**（表格欄位標題寫一次「NT$億」，儲存格只放數字） | NT$B、NT$十億、NT$兆混用 |
| 每股數字 | NT$（股價、EPS、內在價值、目標價） | — |
| 百分點 | pp | 「個百分點」與 pp 混用 |
| 日期 | YYYY-MM-DD | 9/30、10 月底 |
| 季度 | 2Q26、1H26、2026E | Q2'26、26Q2 |
| 倍數 | 28.8x | 28.8 倍 |
| 估算值 | 數字前加 `~`，並在該節註明「自行估算」 | 約、大約、≈ 混用 |

日期還沒確認時寫 `2026-10 下旬（未確認）`。

## 5. 章節骨架（直接複製使用）

標題後面的 `→ **評語**（分數）` 格式是必要的，讀者光看目錄就能拿到每一節的結論。

~~~~markdown
# {代號} {公司名} — 投資評估報告

> 依 `methodology/workflow.md` 五階段流程執行，格式依 `methodology/09-report-format.md`。僅供學習用途，非投資建議。

```
Data & Sources
  Produced:   YYYY-MM-DD（這份報告寫成的日期）
  As of:      YYYY-MM-DD 收盤/盤中（股價 NT$X）；YYYY-MM-DD（最新季報）；YYYY-MM（最新月營收）
  Source:     <法說會、財報、公開資訊觀測站、媒體…，各自附日期>
  Retrieval:  web/tool retrieval | pasted by user | model memory
  Confidence: HIGH | MEDIUM | LOW（一句話說明哪些是自行估算）
```
~~~~
