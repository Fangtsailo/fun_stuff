# 06 — 風險與反方論證

> 來源：`stock-eval.md` Risk Assessment Matrix、Thesis Invalidation；`bear-case.md`（主）。

**核心問題：最壞會怎樣？什麼情況下我是錯的？**

InvestSkill 的做法是：先做一份平衡分析（`stock-eval`），再**刻意用放空者的角度**攻擊它（`bear-case`），最後寫下「論點失效條件」。

---

## 1. 風險矩陣（`stock-eval`）

每項評 L / M / H。

| 類別 | 項目 |
|------|------|
| 業務風險 | 景氣循環、競爭強度、顛覆威脅、客戶集中、供應商集中、法規曝險、ESG / 訴訟 |
| 財務風險 | 槓桿（Net Debt/EBITDA）、流動性、再融資（近期到期債）、債務契約、退休金、表外項目 |
| 估值風險 | 倍數壓縮情境、EPS 少 10% / 20% 的股價反應、高期待股票對小幅下修的不對稱下跌 |
| 總經風險 | 利率敏感度、美元 / 匯率、原物料成本、關稅 / 貿易、地緣政治、反壟斷 |

**再融資風險**：單一年度到期債務 > 30% = 風險升高。
**信用評等**：BBB- / Baa3 是投資等級門檻；負向展望 = 近期可能被降評。

---

## 2. Bear Case 六大支柱

`bear-case` 是**刻意單方面**的紅隊工具，用來逼出反證。規則：可以有立場，但不可捏造；每個論點都要有真實數據或明確標示為假設。

| 支柱 | 問題 | 要找的證據 |
|------|------|------------|
| 1. 估值過高 | 價格是否已反映完美？ | 倍數 vs. 歷史與同業高幾倍；**反向 DCF：現價隱含多少成長？合理嗎？**；便宜是不是價值陷阱？ |
| 2. 基本面惡化 | 生意在變差嗎？ | 營收減速、利潤率壓縮、FCF 與淨利背離、槓桿上升、存貨/應收堆積、**ROIC < WACC** |
| 3. 會計紅旗 | 數字是真的嗎？ | 見 [03-earnings-quality.md](03-earnings-quality.md) §5 |
| 4. 競爭與長期趨勢 | 護城河在侵蝕嗎？ | 失去定價能力、市占流失、商品化、被顛覆、產業結構性衰退、法規 / 訴訟 |
| 5. 管理層 | 管理得好嗎？ | 毀滅價值的併購、高點買回、借錢發股利、內部人大賣、雙重股權、關係人交易、反覆下修指引 |
| 6. 下跌催化劑 | 什麼事件、何時會讓股價重估？ | 0–6 個月：財報 / 下修 / 解禁 / 債務到期；6–18 個月：利潤率回歸 / 競品上市 / 法規決定；結構性：成長放緩導致倍數壓縮 |

**沒有催化劑的空頭論點只是意見。**

---

## 3. 下檔量化

- **空頭目標價** = 保守估計 × 下修後的倍數（要列出計算）
- **情境樹**：基本空頭 vs. 嚴重空頭（例如衰退 + 倍數壓縮），附機率
- **基本面底部**：帳面價值、淨現金、資產價值（誠實的空頭會說出底在哪）

---

## 4. Bear Case 強度分數（0–10，越高越糟）

| 支柱 | 配分 |
|------|------|
| 估值過高 | 0–2 |
| 基本面惡化 | 0–2 |
| 會計 / 盈餘品質紅旗 | 0–2 |
| 競爭與長期威脅 | 0–2 |
| 管理層與資本配置 | 0–1 |
| 催化劑明確度與時點 | 0–1 |

| 分數 | 解讀 |
|------|------|
| 0.0–2.0 | 弱：多頭論點大致完好 |
| 2.1–4.0 | 輕度：有疑慮但不致推翻 |
| 4.1–6.0 | 中度：真實紅旗，考慮減碼 / 避險 |
| 6.1–8.0 | 強：多個獨立負面因素，避開或放空 |
| 8.1–10.0 | 嚴重：深度受損或有詐欺風險 |

---

## 5. Thesis-Killers（強制項目）

空頭論點必須寫出：
- 3–5 個會**推翻空頭論點**的發展（利潤率重新加速、新產品成功、去槓桿、激進投資人 / 收購）
- 最強的多頭反駁，以及為什麼仍不同意（或承認）
- 放空本身的最大風險：估值支撐、軋空、被收購

---

## 6. 論點失效條件（所有框架共通格式）

每份分析結尾都要寫：

```
看多時，論點失效條件：
- [具體指標 + 門檻]，例：F-Score 跌破 3，或 ROIC 連續 2 季低於 WACC

看空時，論點失效條件：
- [具體指標 + 門檻]，例：F-Score 回升到 7 以上，且 ROIC/WACC 利差擴大 > 300bps

何時重跑分析：
- 下一次財報
- 股價較當前 ±15%
- 已過 60 天
- 重大事件（併購、高層異動、法規決定）
```
