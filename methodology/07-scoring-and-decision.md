# 07 — 綜合評分與決策

> 來源：`full-report.md`（綜合評分、衝突處理）；`stock-screener.md`（多檔排名）；`result-validator.md`（分析可信度）；各框架共用的 Investment Signal 區塊。

**核心問題：把前面所有面向合起來，給幾分？該買、持有還是賣？這份分析本身可信嗎？**

---

## 1. 單一公司綜合評分（`full-report`）

### 五階段、依序執行

| 階段 | 子分數 | 權重 | 來源 | 怎麼算 |
|------|--------|------|------|--------|
| 1. 商業與競爭基礎 | Business Quality | **25%** | 01、02、03 | 護城河分數與財務體質取平均 |
| 2. 估值 | Valuation | **25%** | 05 | 10 = 深度折價；5 = 合理；0 = 極度高估 |
| 3. 市場訊號 | Market Signals | 20% | 04 | 內部人、機構、法說會語氣加權平均 |
| 4. 技術面時點 | Technical Setup | 15% | （技術分析，本資料夾不展開） | 強 8–10；中 4–7；弱 0–3 |
| 5. 風險評估 | Risk Profile | 15% | 06 | 風險的反向：低風險 8–10；高風險 0–3 |

**公司品質（階段 1）與價格（階段 2）合占 50%**，是決策主體。

### 綜合分數解讀

| 分數 | 建議 |
|------|------|
| 8.0–10.0 | Strong Buy：所有訊號一致 |
| 6.5–7.9 | Buy：多數訊號正面 |
| 5.0–6.4 | Hold / Watch：訊號分歧 |
| 3.5–4.9 | Underweight：多數訊號負面 |
| 0.0–3.4 | Sell / Avoid：強烈負面 |

沒跑到的模組預設 5.0 分，並標註「未評估」。

## 2. 訊號衝突時的處理規則

1. **基本面優先於技術面**：商業品質與內在價值 > 短期價格走勢
2. **共識優先於異常值**：5 個階段有 4 個同方向時，記錄異常值但不讓它主導
3. **所有衝突都要明確寫出**：不可隱藏矛盾訊號
4. **無法調和的衝突**：例如基本面強 + 極度高估 + 內部人大賣 → 標記「Conflicted — Monitor Only」

**額外規則**：多頭結論如果無法回應 `bear-case` 的 Thesis-Killers，就不是看多，而是「沒被檢驗過」。

## 3. 多檔股票排名（`stock-screener`）

每一面向 0–10 分，子項線性插值後取平均。

| 面向 | 權重 | 子項與滿分 / 零分門檻 |
|------|------|------------------------|
| **Quality** | **25%** | F-Score × 10/9；ROIC−WACC ≥ +10pp = 10、持平 = 5、≤ −10pp = 0；毛利率每年 +3pp = 10、每年 −3pp = 0；D/E < 0.2 = 10、> 3.0 = 0 |
| Valuation | 20% | P/E < 產業中位數 50% = 10、> 200% = 0；P/S < 1 = 10、> 20 = 0；EV/EBITDA < 8x = 10、> 40x = 0；PEG < 0.75 = 10、> 3.0 = 0 |
| Growth | 20% | 營收 YoY ≥ 30% = 10、10% = 5、≤ 0% = 0；EPS YoY ≥ 40% = 10、15% = 5；指引上修 = 10、維持 = 5、下修 = 0 |
| Momentum | 20% | 股價 vs. MA50、MA200；RSI 55–70 最佳；3 個月相對 SPY |
| Sentiment | 15% | 內部人 6 個月淨買 > $5M = 10；機構 QoQ 加碼 ≥ 2% 流通股 = 10；空單減少 ≥ 20% = 10；分析師上修 |

**品質權重最高**，因為它是最持久的因子；情緒權重最低，因為雜訊最多。

**盲點提醒**：這五個面向沒有涵蓋會計品質、治理、客戶集中。選出的標的仍要跑 `bear-case`。

## 4. 標準訊號區塊（所有框架共用）

```
╔══════════════════════════════════════════════╗
║              INVESTMENT SIGNAL               ║
╠══════════════════════════════════════════════╣
║ Signal:      BULLISH / NEUTRAL / BEARISH     ║
║ Confidence:  HIGH / MEDIUM / LOW             ║
║ Horizon:     SHORT / MEDIUM / LONG-TERM      ║
║ Score:       X.X / 10                        ║
╠══════════════════════════════════════════════╣
║ Action:      BUY / HOLD / SELL               ║
║ Conviction:  STRONG / MODERATE / WEAK        ║
╚══════════════════════════════════════════════╝
```

| Score | 意義 |
|-------|------|
| 8.0–10.0 | 強烈看多 |
| 6.0–7.9 | 溫和看多 |
| 4.0–5.9 | 中性 |
| 2.0–3.9 | 溫和看空 |
| 0.0–1.9 | 強烈看空 |

- **Confidence**：HIGH = 數據強、訊號清楚；MEDIUM = 訊號分歧；LOW = 數據有限或互相矛盾
- **Horizon**：SHORT = 1 週–3 個月；MEDIUM = 3 個月–1 年；LONG = 1 年以上

## 5. 分析本身的可信度（`result-validator`）

評完公司後，再評「這份分析」可不可信。五個面向各 20 分：

| 面向 | 檢查項目 |
|------|----------|
| 資料品質 | 來源有標示、資料新鮮度（< 30 天 = 5 分）、完整性、無內部矛盾 |
| 方法論 | 估值方法適合該產業 / 階段、假設有寫明、假設在合理範圍、至少用 2 種方法交叉驗證 |
| 訊號一致性 | 技術與基本面同向、內部人 / 機構同向、總經 / 產業支持論點 |
| 風險涵蓋 | 至少 3 個具體風險、空頭情境有**量化**、正反催化劑都有列 |
| 推理透明度 | 結論有證據支持、考慮過反方論點、承認分析的限制 |

| 總分 | 可信度 |
|------|--------|
| 85–100 | 非常高：可據以行動 |
| 70–84 | 高：小缺口，可作決策依據 |
| 55–69 | 中：有明顯缺口，需補研究 |
| 40–54 | 低：只能當方向參考 |
| 0–39 | 非常低：不可依賴 |

## 6. 最終產出應包含（`full-report` 論點敘述）

1. 投資論點（2–3 段）
2. 多頭理由（3–5 個可量化）
3. 空頭風險（3–5 個，附機率與對內在價值的影響）
4. 綜合評分卡
5. 估值摘要（內在價值、現價、安全邊際、各情境漲跌幅）
6. 進場策略（部位大小：積極 5–7%、中等 2–4%、試單 1–2%）
7. 出場策略（Base / Bull / Bear 目標價、停損、時間框架）
8. 監控計畫（每季追蹤指標、會改變論點的事件、預警訊號）
