# 04 — 管理層與資本配置

> 來源：`stock-eval.md` Management Quality Assessment；`dividend-analysis.md` §9–12（資本配置評分）；`earnings-call-analysis.md` §2、§7；`insider-trading.md` §6–9。

**核心問題：管理層說到做到嗎？會把錢花在報酬高於成本的地方嗎？和股東利益一致嗎？**

---

## 1. 資本配置紀錄

| 面向 | 好的樣子 | 壞的樣子 |
|------|----------|----------|
| ROIC 趨勢 | 5 年持續 > WACC | 低於 WACC |
| 併購 | 被併公司報酬 > WACC | 事後商譽減損 |
| 庫藏股時機 | 在內在價值以下買回 | 在高點買回 |
| 股利 | 配發率可持續、穩定成長 | 借錢發股利 |
| Capex | 區分成長 / 維護，有紀律 | 無差別擴張 |

### 併購紀律：溢價收購風險分數

| 風險因子 | 分數 |
|----------|------|
| 有商譽減損紀錄 | +2 |
| 平均收購 EV/EBITDA > 產業中位數 + 20% | +2 |
| 在市場高點收購 | +1 |
| 頻繁大型交易（5 年內 > 3 件） | +1 |
| 併購後利潤率壓縮 | +1 |
| 併購後管理層流動 | +1 |

**0 = 有紀律；3+ = 注意；5+ = 併購成癮風險**

**偏好型態**：> 60% 有機成長，併購只是補強，不是成長替代品。

### 資本配置品質綜合分數（0–10）

| 項目 | 權重 |
|------|------|
| 股利安全性 | 20% |
| 股利成長品質 | 10% |
| 庫藏股紀律 | 20% |
| 併購紀錄 | 20% |
| 債務管理品質 | 15% |
| FCF 運用效率 | 15% |

| 分數 | 解讀 |
|------|------|
| 9–10 | 卓越，複利機器 |
| 7–8 | 優秀配置者 |
| 5–6 | 普通 |
| 3–4 | 低於平均，錯誤配置風險 |
| 0–2 | 價值毀滅者 |

## 2. 股利安全分數（0–100）

| 項目 | 配分 | 評分 |
|------|------|------|
| FCF 配發率 | 25 | < 50% = 25；50–70% = 20；70–85% = 10；> 85% = 0 |
| FCF 覆蓋倍數 | 20 | > 2x = 20；1.5–2x = 15；1.0–1.5x = 8；< 1.0x = 0 |
| Debt / EBITDA | 20 | < 1.5x = 20；1.5–2.5x = 14；2.5–3.5x = 7；> 3.5x = 0 |
| 盈餘穩定性 | 20 | 5 年皆正 = 20；1 年衰退 = 12；2 年以上衰退 = 4 |
| 股利紀錄 | 15 | 10 年以上 = 15；5–9 年 = 10；2–4 年 = 5；< 2 年 = 0 |

| 分數 | 等級 |
|------|------|
| 90–100 | A+ 非常安全 |
| 75–89 | A 安全 |
| 60–74 | B 勉強安全 |
| 45–59 | C 風險升高 |
| 30–44 | D 不安全 |
| 0–29 | F 危險 |

**警訊**：股利成長率 > EPS 成長率 = 靠提高配發率撐，不可持續。

## 3. 指引準確度（最近 8 季）

| 命中率 | 解讀 |
|--------|------|
| ≥ 75%（6/8 以上） | 強 |
| < 50% | 過度承諾，或能見度惡化 |

另外判斷管理層是習慣保守（sandbagging）還是習慣樂觀。

## 4. 法說會語氣

| 類型 | 指標 |
|------|------|
| 有信心 | 肯定用語（「將」「承諾」「有信心」）、窄區間的具體指引、主動說明挑戰與解方 |
| 謹慎 | 避險用語（「可能」「希望」）、區間很寬或沒有具體目標、迴避困難問題 |
| **紅旗** | 閃躲或防衛性回答、頻繁更改財務定義、把問題都怪給外部因素、揭露細節比前幾季少 |

法說會紅旗清單：
- **財務**：連續多季未達指引；營收成長但利潤率下滑；FCF 遠低於淨利；一次性費用變常態
- **營運**：客戶集中、關鍵高層離職、產品延遲、市占流失、併購整合失敗
- **治理**：董事會衝突、關係人交易、內部人賣股、沒有接班計畫

## 5. 內部人持股與交易

### 持股利益一致性

| 對象 | 門檻 |
|------|------|
| CEO 持股 | > 3% 有意義；> 10% 高度一致 |
| 內部人整體 | > 20% 強；10–20% 尚可；< 10% 較弱 |

### 交易訊號

| 看多型態 | 看空型態 |
|----------|----------|
| 多位內部人 1–2 週內集中買進 | 多位內部人集中賣出 |
| 資深高層第一次買進 | CEO / CFO 賣出大比例持股 |
| 股價弱勢時買進 | 以前只買的人第一次賣 |
| 持股增加 > 25% | 股價下跌仍在賣（急著出場） |
| 在 52 週低點附近買進 | 高層離職後賣股 |

**中性（雜訊）**：10b5-1 預排計畫、例行選擇權履約、< 5% 持股的分散、繳稅扣股、贈與。

**高嚴重度紅旗**：
- CEO / CFO 賣出 > 50% 持股
- 在財報不如預期或下修指引前集中賣出
- 在封閉期交易
- Form 4 延遲申報（> 2 天）且無解釋

## 6. 薪酬結構

- 獎金與股權歸屬是否連結 ROIC、FCF、TSR
- 股權歸屬期 3 年以上較佳
- Say-on-pay 股東支持率
- **紅旗**：保證獎金、選擇權重新定價、控制權變更時的巨額遣散費
